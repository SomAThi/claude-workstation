# FULL и Cowork

На текущем VPS MODE=LITE. Cowork не запускался: RAM <8 GB, /dev/kvm отсутствует. Не создавайте фиктивное устройство и не пытайтесь заменить KVM эмуляцией.

FULL подготавливает qemu-system-x86, ovmf, virtiofsd, группу kvm для workstation. preflight проверяет CPU flag, API 12 и настоящий ioctl KVM_CREATE_VM с закрытием дескриптора. verify повторяет KVM-проверку под непривилегированным пользователем. Это проверяет инфраструктуру, но не запуск Cowork.

На будущем FULL-сервере после входа в Claude:

1. Открыть Cowork. При ошибке сохранить её текст без секретов.
2. Разрешить официальную загрузку workspace image; убедиться в наличии свободных 25+ GB под образ.
3. Запустить безопасную задачу, создать документ в явно выбранной тестовой папке.
4. Проверить чтение, изменение и сохранение тестового файла.
5. При SMB отдельно выбрать /mnt/mac-shared через поддерживаемый интерфейс и повторить тест. Если это не поддерживается — зафиксировать ограничение, не менять изоляцию VM.
6. Проверить восстановление после нового входа и штатной перезагрузки с согласия владельца.

Заполнить docs/COWORK-RESULT.md: дата, версии Desktop/QEMU/kernel, KVM под пользователем, VM launch, folder read/write, SMB folder, ошибки, подтверждение владельца. До этого FULL имеет статус «подготовлен, ожидает ручной проверки», а не «полностью работает».
