# MacBook: подключение и одна общая папка

На Mac установите только официальные клиенты Tailscale и RustDesk. Claude Desktop/Code остаются на Ubuntu. Войдите в Tailscale на обоих устройствах в одну разрешённую сеть. В административной панели ограничьте доступ к VPS TCP 21118 вашим Mac. Не открывайте 21118 или SMB 445 на публичном адресе роутера/VPS.

После авторизации VPS выполните на сервере scripts/enable-rustdesk.sh. Узнайте его адрес командой `tailscale ip -4`. В RustDesk на Mac укажите `100.x.y.z:21118`. Используйте уникальный пароль, прочитанный только в вашем root SSH-терминале из /var/lib/claude-workstation/rustdesk-password. Это отдельный пароль от пароля входа пользователя Ubuntu. Проверьте оба этапа: вход RustDesk и экран LightDM пользователя workstation.

Включите текстовый Clipboard в разрешениях RustDesk. Проверьте копирование тестовой строки в обе стороны, мышь, клавиатуру RU/EN, изменение размера окна и полноэкранный режим. Отключите клиент, подключитесь снова: открытые окна должны остаться. После перезагрузки ожидается экран входа, а не автоматически вошедший пользователь. Полный autologin намеренно не включён.

Для ярлыка используйте сохранённое соединение/избранное RustDesk после первого успешного входа. Не встраивайте пароли в ярлык или URL.

## SMB

1. Создайте ~/Documents/Claude-Shared. Не делайте общими Documents или домашний каталог целиком.
2. В macOS создайте отдельного пользователя типа «Только общий доступ», без административных прав. Его пароль вводится только локально при настройке сервера, не отправляется в чат.
3. Системные настройки → Основные → Общий доступ → Общий доступ к файлам. Добавьте только Claude-Shared. Выделенному пользователю дайте чтение и запись, Everyone — нет доступа. Убедитесь, что выделенный пользователь не имеет доступа к другим опубликованным папкам. В параметрах SMB включите только нужного пользователя.
4. Узнайте Tailscale IP Mac. Не включайте переадресацию SMB на роутере. При необходимости ограничьте входящий SMB правилами macOS/корпоративной сети до tailnet: глобальное включение File Sharing само по себе может сделать SMB доступным в LAN.
5. На VPS выполните `sudo ./scripts/setup-mac-share.py` из каталога проекта и введите IP, имя общего ресурса, отдельного пользователя и пароль.

Скрипт принимает только Tailscale IP, требует SMB3 (3.0 или новее) с шифрованием (`seal`), создаёт root-only credentials, mount с nosuid,nodev,noexec, uid workstation и правами 0600/0700. Добавляет automount/nofail и тайм-аут 15 секунд. При недоступном Mac доступ к пути может ждать тайм-аут; не держите рабочий проект приложения на отключаемом диске. Тест создаёт новый cw-test-UUID.txt, проверяет чтение и изменение и оставляет его для вашего осмотра.

Постоянное отключение: закрыть использующие папку приложения, выполнить scripts/disconnect-mac-share.sh, затем удалить только отдельную строку /mnt/mac-shared из /etc/fstab и root-only credentials. Файлы Mac скрипт не удаляет.

Подключение каталога к Cowork выполняется только через официальный интерфейс выбора папок, после отдельной проверки в FULL. SMB mount на хосте не доказывает его доступность внутри VM.
