# Миграция

## Чистая установка

Скопируйте только исходный установочный архив (без runtime/node/browser, credentials и состояния /var/lib). Распакуйте на Ubuntu 24.04 x86_64 и выполните `sudo ./install.sh`. AUTO выберет подходящий режим. Авторизуйте Claude/Tailscale отдельно; каждый VPS получает новую идентичность и новый пароль RustDesk. SSH host keys не переносятся.

## Рабочие данные

Под workstation выполните `./scripts/backup.sh /home/workstation/cw-backup.tar.gz`. Каталоги Projects и Documents включаются по allowlist; каталоги auth/browser/SSH/Tailscale не включаются. Из проектов исключаются .git, .env*, приватные ключи известных расширений, credentials, зависимости. Никакой фильтр не способен распознать все произвольно названные секреты в пользовательских документах: перед выносом архива самостоятельно проверьте содержимое (`tar -tzf`), храните его защищённо.

На новой машине после установки под workstation: `./scripts/restore.sh /path/to/cw-backup.tar.gz`, ввести RESTORE. Архив проверяется на traversal, links/devices, количество и общий размер; распаковывается исключительно в новый workstation-restore-* каталог с правами 0700/0600. Существующие данные не перезаписываются. Проверьте содержимое и копируйте выбранные файлы вручную. Исполняемые права скриптов при необходимости восстановите после осмотра.

Полный профиль Claude не копируется: он может содержать сессии и секреты. Перенос всех чатов не обещается. Войдите в тот же аккаунт и проверьте доступную серверную историю. Экспорт пользовательских данных выполняется отдельным официальным механизмом аккаунта; этот установщик его не запускает. Проекты и документы на диске переносятся отдельно.

Ссылка на текущую документацию экспорта должна проверяться перед переносом; используйте Help Center Claude, раздел export data. Для текущего проекта автоматическое восстановление истории/активных AI-задач не реализовано.

Официальный экспорт: https://support.claude.com/en/articles/9450526-export-your-claude-data — Settings → Privacy → Export data. Экспорт не является поддерживаемым импортом в другой личный аккаунт. Это проверено по документации на дату развёртывания.
