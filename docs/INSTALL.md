# Установка

Поддерживаемая и проверяемая цель этой версии: Ubuntu Server 24.04 LTS x86_64. Другие архитектуры/версии отклоняются явно. Развёртывание на существующий рабочий сервер не рекомендуется: сначала снимок у провайдера. Установщик не меняет SSH, не форматирует диски и не перезагружает машину.

```bash
sudo ./install.sh                          # AUTO
sudo ./install.sh --mode LITE
sudo ./install.sh --mode FULL
./install.sh --mode AUTO --preflight-only  # только проверка
```

AUTO проверяет RAM, свободный диск, CPU virtualization flags, KVM API и KVM_CREATE_VM. FULL выбирается при >=7500 MiB физической RAM (учёт накладных расходов номинальных 8 GB), >=50 GiB свободного диска и рабочем KVM. LITE требует >=3500 MiB RAM и >=20 GiB свободного места. 4+ vCPU и 16 GB рекомендованы для FULL. FULL означает подготовленную инфраструктуру; это не успешная проверка Cowork.

Использованы Bash и Python стандартной библиотеки вместо Ansible: один сервер, локальные управляемые файлы и прямые проверяемые шаги без дополнительного управляющего слоя. Скрипты разделены на preflight, system, applications, configure и verify. config.example.env — справка о параметрах; он не исполняется и не загружается как shell-код. Имя пользователя в этой версии фиксировано: workstation.

Установщик требует root и интернет, блокирует конкурентные запуски. Логи: /var/log/claude-workstation, состояние: /var/lib/claude-workstation. Повторный запуск сохраняет управляемые конфигурации, если они уже существуют. Новые версии шаблонов не перезаписывают ваши изменения: сравнивайте вручную. Он не запускает Cowork на LITE.

Пакеты Claude Desktop и Code поступают из отдельных официальных подписанных APT-репозиториев; ключи проверяются по fingerprint 31DDDE24DDFAB679F42D7BD2BAA929FF1A7ECACE. CLI устанавливается отдельно для терминального сценария; не подменяет внутренний runtime Desktop. Tailscale — официальный подписанный репозиторий noble. RustDesk 1.5.0 — официальный GitHub release и SHA256 из метаданных GitHub. Node 24.22.1 — nodejs.org, SHA256 закреплён из официального SHASUMS256.txt. npm пакеты и integrity закреплены package-lock.json. Эти SHA256-проверки не являются отдельной подписью разработчика RustDesk/Node.

Системные Ubuntu/Anthropic/Tailscale APT-пакеты получают текущие доступные версии; фактический список сохраняется в installed-versions.tsv. Это воспроизводимое окружение, а не побитово идентичный образ. Для точного повторения исторических APT/snap версий нужен отдельный snapshot/mirror; этот пакет его не создаёт. Node/RustDesk/Playwright закреплены. Chromium snap обновляется через Ubuntu Snap Store.

Графика: LightDM + Xorg dummy + XFCE. Автовход выключен. После загрузки доступен экран входа, после ручного входа — пользовательский сеанс и автозапуск Claude. Отключение клиента не должно завершать сеанс; это требует проверки с Mac. Пароль нового пользователя генерируется однократно, хранится root-only в /var/lib/claude-workstation/initial-login-password; получить в собственном SSH-терминале, сменить через passwd под workstation. Не пересылайте его в чат.

RustDesk до авторизации Tailscale выключен. Пакет имеет postinst с автозапуском; установщик предварительно создаёт ConditionPathExists и сетевое ограничение службы. После авторизации:

```bash
sudo tailscale up --accept-routes=false --accept-dns=false
sudo ./scripts/enable-rustdesk.sh
```

Скрипт проверяет реальное применение cgroup BPF IPAddressDeny на отдельном процессе, затем разрешает службе только localhost и адреса tailnet IPv4/IPv6. Firewall и SSH не меняются. Уникальный сильный пароль RustDesk хранится root-only, не включается в пакет. Не копировать его на новый VPS. Tailscale ACL должен разрешать только вашим устройствам TCP 21118.

Два браузера: ручной Chromium — официальный Ubuntu snap; автоматизация — закреплённый браузер Playwright Chrome for Testing, отдельная изолированная сессия. MCP общается через stdio, наружу не открывает HTTP/CDP. AppArmor остаётся активным, точечный userns-профиль относится только к root-owned бинарнику автоматизации.

Общая папка — отдельный этап через scripts/setup-mac-share.py; см. MAC_SETUP.md. Не включайте автоматическое одобрение операций в Claude.

Для браузеров настроены пользовательские systemd scopes с MemoryHigh=900M и MemoryMax=1200M, по одному процессному дереву каждого режима. Это может завершить тяжёлую браузерную сессию вместо вытеснения всей RAM сервера. Перед AI-тестом желательно закрывать лишние ручные вкладки. Служба user systemd и bus становятся доступны при пользовательском входе в GUI.
